# Punto & Gestión — Versiones

Este repositorio contiene únicamente instaladores publicados, notas de versión
y el manifiesto firmado `latest.json`.

El código fuente de Punto & Gestión se conserva en un repositorio privado
separado y no se publica aquí.

Cada instalador es validado por la aplicación mediante:

- firma digital Ed25519 del manifiesto;
- verificación SHA-256 del archivo descargado;
- copia de seguridad previa a la actualización.
