# Punto & Gestion 2.1.13

Version de mantenimiento y compatibilidad para las aplicaciones instaladas.

## Correcciones

- Se corrige el selector de clientes del POS en iPhone: las filas son mas compactas y la lista tiene desplazamiento tactil dentro del espacio visible sobre el teclado.
- Se corrige la descarga de listas de precios en JPG en la aplicacion instalada cargando automaticamente el motor `html2canvas` incluido en el instalador.
- Se actualiza la version a un numero mayor (`2.1.13`) para que el actualizador no dependa de sufijos con letras.

## Compatibilidad

- Se conservan los datos locales, la configuracion del comercio y las mejoras de las versiones anteriores.
- La importacion de listas `.xlsx`, `.xls` y PDF continua disponible en la aplicacion instalada.
